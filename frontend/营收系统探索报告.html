「营收系统」是巴州焉耆自来水营收管理平台的核心业务子系统（对应微前端子应用 /billing/#/），承载自来水从用户开户建档到水费收缴、账务处理、票据开具的全生命周期营收业务。其业务主线可概括为：开户建档 → 立户 → 抄表 → 计费出账 → 收费 → 开票，并配套表务资产管理、优惠政策、对账与报表分析能力。

三、各模块职责描述

以下对每个一级模块，从核心职责、关键功能点、主要操作项、业务定位四个维度进行描述，并拆解其子模块作用。

1
用户管理 （25 入口 · 营收业务起点）
核心职责
管理自来水用户的全生命周期档案，是营收业务的起点与核心主数据。负责开户建档（立户）、用户信息维护、状态管控、优惠政策与定额/附加费配置。
关键功能点
① 用户档案管理（含立户开户入口、档案查询、批量修改、短信通知、导出）；② 用户状态机（正常/报停/销户，含申请→审核→记录→日志）；③ 水价批量调整与档案快捷变更；④ 优惠政策的申请/审核/查询/性质设置；⑤ 合算号（合并缴费号）管理；⑥ 定额阶梯水价用户认定与系数；⑦ 附加费、征信、考核表、合同预警、财务序号。
主要操作
立户/开户、查询/重置/更多查询、批量修改、短信通知、导出档案资料、批量变更表册、申请/审核状态变更、优惠申请/审核、档案快捷变更、水价批量调整。
业务定位
所有营收业务（抄表、计费、收费）的主数据来源。一个用户必须先在此立户生成档案号/用户编号，后续抄表计费才得以关联。页面含 25+ 字段（档案号、用水性质、收费方式、价格、票据类型、银行账号、供水区域等）支撑精细计费。
用户档案管理 /user/archives
核心档案页。筛选：自来水公司、档案号、用户名称、用户类型、收费方式、用户状态、立户时间、用水分类、供水区域等 20+ 条件；操作：立户、批量修改、短信通知、导出、批量变更表册；列表含 26 列明细。
用户状态管理（申请/审核/记录/日志）
报停、销户、复装等状态变更的「申请 → 审核」闭环，全程留痕，属需审批功能。
用户资料处理（水价批量调整/档案快捷变更/批量立户/变更记录/编辑权限）
批量与快捷维护工具，提升大批量用户建档/调价效率，编辑权限控制可改字段范围。
优惠政策管理（申请/审核/查询/性质设置）
困难户、政策性减免等优惠的「申请 → 审核」流程，性质设置定义优惠类型与规则。
定额阶梯管理（认定/用户管理/增长系数/用水查询）
对定额用水户（如农村/特定行业）的认定、阶梯与增长系数配置。
附加费管理 / 用户征信 / 考核表 / 合同预警 / 财务序号
附加费类型与用户级设置、征信评级、考核表（总表/考核计量）、合同到期预警、财务对接序号。
2
抄表管理 （13 入口 · 计量与计费触发）
核心职责
完成用水量的采集、校验与开账计费，是营收从「实物计量」到「金额账单」的转化中枢。维护抄表册、线路、月结与催缴。
关键功能点
① 抄表录入（本月读数、本次用量、估抄、异常表况）；② 校验水量审核/记录（对异常水量二次确认）；③ 开账计费（按表册/档案批量生成账单，拆分基本费/排污费/阶梯费/加价费/附加费/垃圾费）；④ 表册管理与抄表线路规划；⑤ 催款管理；⑥ 抄表复核与（管理员）抄表修改；⑦ 抄表月结与现场情况反馈（移动端）。
主要操作
抄表/追加抄表/抄表检查、设置抄表日期与人员、水量清零、导出 Excel；按档案/表册开账、取消计费；月结。抄表状态机：未抄 → 已抄 → 已计费 → 已收费。
业务定位
营收计费环的触发点。抄表录入产生「本月用量」，校验后由「开账计费」生成应收账单（出账），账单状态由「已抄」转为「已计费」，方可进入收费环节。
抄表录入 /mrm/readmeter
核心抄表页。筛选：公司、档案号、抄表月份、表况、抄表状态、是否估抄等；操作：抄表、追加抄表、抄表检查、设置日期/人员、水量清零、导出；字段覆盖上次/本次读数、校验量、实际用量、表况、异常原因等。
校验水量审核 / 校验水量记录
对偏大/偏小/异常水量进行二次校验与确认，保证计费基数准确。
开账计费 /mrm/chargemanage
计费核心。按选中用户档案或表册开账，生成账单金额（基本费+排污费+阶梯费+加价费+附加费+垃圾费=合计），支持取消计费。列表展示各费用分项与计费时间。
表册管理 / 抄表线路 / 催款管理 / 抄表复核
抄表组织（册、线路）、欠费催缴、数据复核的质量控制环节。
抄表修改（管理员）/ 抄表计划（月结/日志）/ 现场情况反馈
管理员纠错通道、月度结算与移动端现场上报。
3
收费管理 （6 入口 · 资金收入入口）
核心职责
面向用户的水费收缴执行层，将「已计费账单」转化为「实收资金」。是营收资金流入的主通道。
关键功能点
① 窗口收费（柜台现金/二维码/POS/转账支票，含欠费合计、违约金、预存、多户合计、减免申请、票据设置）；② 收费结账（收银日结）；③ 银行转账；④ 营业外收入；⑤ 银行代扣（批扣）；⑥ 撤销收费记录（查询已撤销）。
主要操作
按档案号/用户搜索 → 选择未收账单 → 选择收费渠道 → 录入实收/预存 → 收费 → 自动生成收据号/发票号 → 打印票据。支持减免申请、垃圾费拆分、合算号汇总、多户合计。
业务定位
营收闭环的资金落点。收费成功后账单状态由「已计费」转为「已收费」，并触发票据开具与实收统计。窗口收费与银行代扣/转账构成多通道收款体系。
窗口收费 /charge/toll
核心收费页（详情/列表双视图）。用户信息面板 + 欠费账单明细（基础费/排污费/阶梯费/加价费/附加费/垃圾费/违约金/减免）+ 收费渠道（现金/二维码/POS/转账支票）+ 实收/预存 + 票据设置（收据号/发票号）+ 减免申请/多户合计/垃圾费拆分。含未收账单、已收账单、收费记录、合算号汇总多标签。
收费结账 / 银行转账 / 营业外收入 / 银行代扣 / 撤销收费记录
收银日结、单笔转账、非水费收入、批量代扣、撤销流水查询，覆盖各类收款与对账场景。
4
账务处理 （12 入口 · 账面调整与风控）
核心职责
对已完成/未完成的账单与资金进行调整、冲减、减免、核销，保证账面准确，是营收的「财务内控」层。
关键功能点
① 撤销收费（撤销 + 记录）；② 应收减免（账单减免申请 → 审核）；③ 余额管理（余额处理 + 转移记录，预存款划转）；④ 呆坏账管理（申请 → 审核 → 历史 → 日志，长期欠费核销）；⑤ 账单冲正（冲正 + 记录，纠错）。
主要操作
减免申请/审核、撤销收费、余额转移、呆坏账申请/审核、账单冲正。多数含「申请 → 审核」双步审批。
业务定位
营收账面的纠错与风控中枢。处理优惠减免、退费冲正、预存余额、呆账核销等异常账务，与收费管理、用户管理（优惠）形成联动。
5
票据管理 （7 入口 · 票证合规）
核心职责
管理水费票据的库存与开具，保证收费凭证合规可追溯。含收据/发票开具与票号生命周期管理。
关键功能点
① 已收开票（收费后开具收据/发票）；② 作废·重开（票据纠错）；③ 未收开票（预开票）；④ 票号管理（票据入库/发放/接收/移交，票号段全生命周期）。
主要操作
开票、作废、重开、补开、票据入库/发放/接收/移交；票据设置（起始票号段）。
业务定位
收费的凭证闭环。窗口收费产生「收据号/发票号」，此处完成正式票据开具与票号库存管控，满足财税合规。
6
表务管理 （22 入口 · 计量资产）
核心职责
管理水表资产全生命周期与阀门管控，是抄表计量的物理基础。含换表、拆装、库存、档案、开关阀。
关键功能点
① 换表管理（申请 → 确认 → 记录 → 批量换表，换表影响计费基数）；② 拆装表管理（申请/确认）；③ 库存管理（鉴定/入库/出库/调拨/调拨确认/查询/盘点）；④ 基础信息（仓库/水表产品/厂家）；⑤ 水表档案；⑥ 开关阀管理（派工关阀/关阀登记/派工开阀/开阀登记）；⑦ 周期调表。
主要操作
换表申请/确认、拆装申请/确认、表具出入库与调拨、库存盘点、阀门派工与登记、周期调表。换表/拆装含「申请 → 确认」审批。
业务定位
营收计量的资产支撑。水表是计费载体，换表/拆装直接触发计费参数变化；阀门管控支撑欠费关阀、复装开阀等催缴手段。
7
报表中心 （29 入口 · 数据洞察）
核心职责
对营收全链路数据进行汇总、分析与对账，为经营决策提供依据。是营收系统的「管理驾驶舱」。
关键功能点
① 数据总览（Dashboard）；② 自定义报表（月水费/污水汇总明细、预存销账、同环比）；③ 应收分析（用户账单查询）；④ 实收分析（收费数据/汇总、预交款月报、每日余额、回收率）；⑤ 抄表分析（抄表率、年度用水）；⑥ 欠费统计；⑦ 其他（优惠减免水量、产销差）；⑧ 第三方对账（银行/微信/支付宝）；⑨ 短信查询。
主要操作
条件查询、导出 Excel、报表钻取。对账模块用于与银行/第三方支付渠道核对实收。
业务定位
营收的决策与监管层。将抄表、计费、收费、账务数据转化为经营指标（回收率、产销差、欠费），并通过对账保障资金一致。
8
业务参数 （21 入口 · 系统配置底座）
核心职责
配置营收所需的基础规则与参数，是计费、收费、打印的「规则引擎」与系统运行底座。
关键功能点
① 区域/营业网点基础数据；② 价格管理（单价性质/基础单价/排污价/加价/阶梯价/帐目项，计费公式核心）；③ 违约金类型、数据权限、用户开户行；④ 打印插件与模板；⑤ 抄表APP；⑥ 业务配置（参数/字典/计费规则/系统信息）；⑦ 数据验证（健康度/上线验证）。
主要操作
新增/编辑价格、配置阶梯与加价规则、设置违约金、配置打印模板、维护字典与计费规则、数据校验。
业务定位
营收业务运行的规则与配置底座。开账计费时所用的单价、阶梯、加价、排污、违约金等全部来源于此模块，是计费准确性的根本保障。
9
快捷查询 （1 入口 · 综合查询）
核心职责
提供客户综合信息的一站式查询入口，整合档案、账单、抄表、收费等多维度数据。
关键功能点
单一「快捷查询」页面（PanelCustomerBase），按客户聚合展示全量信息，便于客服/柜台快速响应。
主要操作
条件检索、客户全景信息查看。
业务定位
面向一线人员的效率工具，无需在各模块间跳转即可获取用户全貌。
